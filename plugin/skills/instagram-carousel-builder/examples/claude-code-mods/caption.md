Claude Code mods can rewrite or skip what Claude does next. They also run with your permissions.

Mods are a new kind of Claude Code plugins: they run inside it and change how it looks and behaves. You install one like any plugin, with /plugin install <name>@<marketplace>. People are already building game-style HUDs, a shared Doom lobby to play while Claude works, and Anthropic's blast-radius sample, which pauses rm -rf and force pushes until you press Proceed.

The catch: mods aren't sandboxed. Before you install one, run claude plugin validate to see every event it hooks and every API call it makes.

Send this to the teammate who'll install your first one.
